Deploy in Seconds

Turnkey container ready for your homelab, LXC, or VPS.

# 1. Pull the official FQD container image
docker pull ghcr.io/piyushkumarjiit/fqd:latest

# 2. Run standalone on port 1455
docker run -d \
  --name fqd \
  -p 1455:8795 \
  -v fqd_data:/app/data \
  ghcr.io/piyushkumarjiit/fqd:latest

# → Open http://localhost:1455 in your browser

Frequently Asked Questions

What is Fleet Quota Display (FQD)?

FQD is an observability cockpit designed for developers running multi-agent swarms or teams with pooled AI subscriptions. It brings subscription quotas (CLIProxy) and API key spend (LiteLLM) into one cohesive dashboard.

Can I monitor multiple accounts of the same provider?

Yes! FQD was specifically built to handle pools of accounts (e.g. 14 Antigravity slots, multiple Claude Pro seats) side-by-side without session collision.

Where are credentials stored?

Credentials never leave your own server or container. They are AES-256-GCM encrypted on disk. FQD connects strictly to official provider endpoints and never sends telemetry to any third party.

Is FQD free and open source?

Yes, FQD is 100% free and released under the permissive MIT License on GitHub.
